iPhone: ショートカット

iOS 26の手順:
1. ショートカットアプリ → 新規作成 → 名前「お品書き追加」
2. 下部ツールバーの ⓘ(詳細) → 「共有シートに表示」をON → 完了
3. (推奨) 先頭の入力アクションの「◯個」→ 消去 → URLだけON
4. アクション「URLを開く」を追加
   URL = https://chihirominahara.github.io/oshina_gaki/?add=
   の末尾に「変数を選択」→「ショートカットの入力」を挿入
5. Xのツイート → 共有 → お品書き追加

PC: ブックマークレット

ブックマークに登録して、Xのツイート画面で押すと追加できます。

javascript:(()=>{const m=location.href.match(/\/(?:status|statuses)\/(\d{10,25})/);if(!m){alert('ツイートを開いてから実行してね');return;}open('https://chihirominahara.github.io/oshina_gaki/?add='+m[1],'_blank');})();
